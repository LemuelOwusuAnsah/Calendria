\# Calendria



A modern, modular online calendar built with vanilla JavaScript and Bootstrap 5. Check any date, add events, track public holidays, and export your schedule — all in a clean, responsive interface with dark/light themes.



\## Features



\- \*\*Interactive Calendar\*\* — Month view with swipe, scroll-wheel, and keyboard navigation

\- \*\*Jump to Date\*\* — Enter any day, month, or year and go there instantly

\- \*\*Events\*\* — Add, edit, and delete events per day with titles, times, descriptions, and color labels

\- \*\*Public Holidays\*\* — Automatic Ghana public holidays plus international observances

\- \*\*Recent History\*\* — Quick access to recently viewed dates

\- \*\*Export \& Backup\*\*

&#x20; - Month to CSV

&#x20; - Month to JSON

&#x20; - Print / PDF

&#x20; - Full backup (JSON)

&#x20; - Restore from backup

\- \*\*Dark / Light Theme\*\* — Toggle with persistent preference

\- \*\*Offline Ready\*\* — Bootstrap and icons are vendored locally; works without an internet connection

\- \*\*Fully Responsive\*\* — Optimized for desktop, tablet, and mobile
